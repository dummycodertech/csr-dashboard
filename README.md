# CSR Workforce Analytics Dashboard

> **All data in this project is 100% synthetic / demo data. No real employee or company data is used.**

A full-featured HR/People Analytics platform built as a portfolio project, containing two tools in one app:

1. **Workforce Analytics Dashboard** — replicates a 33-pivot-table Excel HR dashboard for a 1,000-employee CSR workforce
2. **Onboarding Compliance Tracker** — an interactive web version of an onboarding checklist Excel tracker (130 employees across Onrole & Offrole)

## Features

### Workforce Dashboard
- **4 KPI cards**: Total headcount · Total CTC (₹ Cr) · Avg CTC (₹L) · % Retiring in 3 yrs
- **10 chart panels**: Headcount by BU · Gender ratio · Age group distribution · Onroll/Offroll · Cost by BU · Retiring in 3 yrs · Project-wise table · Region summary · Top-10 locations · State-wise table
- **Global filter sidebar** with 10 multi-select dimensions (Gender, Type, Business, Age Group, Region, State, Project, Role, Location, Retiring) — all charts and KPIs react live
- **Dismissible active-filter chips** below the KPI row
- **Collapsible sidebar** (264px ↔ 52px icon rail)

### Onboarding Tracker
- **Onrole (80 employees)** and **Offrole (50 employees)** tab switcher
- **Colour-coded checklist table**: 🟢 Yes · 🔴 No · ⚫ N/A — exactly mirroring the original Excel tracker layout
- **Cell highlight mode**: click Yes / No / N/A filter button → matched cells go solid colour, non-matched cells dim — instantly spots gaps
- **Section-banded column headers**: Pre Joining (blue) · After Selection (amber) · Post Joining (green) with shortened rotated labels
- **Completion bars by stage** with adaptive colour (green ≥75% · amber ≥40% · red <40%)
- **Search** by name / employee ID / designation
- **Section filter** to focus on one stage's columns at a time

### Both pages
- **Light / dark mode toggle** (persisted to localStorage)
- Fully responsive grid layout

## Dataset

### Workforce (`src/data/employees.js`)
1,000 synthetic employee records generated by `scripts/generate_data.py`.

Key rules:
- Region → State → Location mappings geographically consistent (33 locations, 12 states, 5 regions)
- Role-based CTC bands enforced for all 12 roles
- `retirement_date` = birth year + 58-year retirement age
- `retiring_in_3_years` = Yes if retirement_date ≤ 2029-07-29

### Onboarding Tracker (`src/data/trackerData.js`)
130 demo employee records converted from `Demo_Onboarding_Tracker.xlsx` using `scripts/generate_tracker.py`.
- Onrole: 80 employees · 31 checklist fields
- Offrole: 50 employees · 21 checklist fields

## Getting Started

### Prerequisites
- [Node.js](https://nodejs.org) LTS v18+

### Install & run locally

```bash
cd csr-dashboard
npm install
npm run dev
```

Open **http://localhost:5173**

### Regenerate data (optional)

```bash
# Regenerate workforce dataset
python scripts/generate_data.py

# Re-parse onboarding Excel (update path inside script if needed)
python scripts/generate_tracker.py
```

### Build for production

```bash
npm run build
```

## Deployment (Vercel)

This repo is connected to Vercel — every push to `main` auto-deploys.

### Manual deploy via CLI

```bash
npm install -g vercel
vercel login
vercel --prod
```

### Fresh deploy via GitHub

1. Fork / push this repo to GitHub
2. Go to [vercel.com/new](https://vercel.com/new) → Import repo
3. Framework preset: **Vite** → Deploy
