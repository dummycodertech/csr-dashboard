# CSR Workforce Analytics Dashboard

> **All data in this project is 100% synthetic. No real employee or company data is used.**

A full-featured HR/People Analytics dashboard built as a portfolio/college project, replicating an Excel pivot-table dashboard for a ~1,000-employee CSR workforce.

## Live Demo

Deploy to Vercel — see [Deployment](#deployment) below.

## Tech Stack

| Layer | Choice |
|---|---|
| Framework | React 18 (functional components + hooks) |
| Build tool | Vite 5 |
| Styling | Tailwind CSS v3 + CSS custom properties |
| Charts | Recharts 2 |
| Icons | Lucide React |
| Fonts | Plus Jakarta Sans (UI), IBM Plex Mono (data values) |
| Deployment | Vercel |

## Features

- **16 chart panels**: Headcount by BU, Gender ratio, Age group distribution, Onroll/Offroll, Cost by BU, Retiring in 3 yrs, Project-wise table, Region summary, Top-10 locations, State-wise table, CTC Salary Band Distribution, Tenure vs Retirement Risk, Salary Heatmap, Hiring Vintage, Project Health Radar, Gender & Employment Type by Business
- **4 KPI cards**: Total headcount, Total CTC (Cr), Avg CTC (L), % Retiring in 3 yrs
- **Global filter sidebar**: 10 multi-select filters (Gender, Type, Business, Age Group, Region, State, Project, Role, Location, Retiring) — all charts and KPIs react live
- **Light / dark mode**: toggle in the header, persisted to localStorage
- **Collapsible sidebar**: collapses to icon rail to maximise chart space
- **Active filter chips**: dismissible pills below the KPI row showing what's applied

## Dataset

`src/data/employees.js` — 1,000 synthetic employee records generated by `scripts/generate_data.py`.

Key data rules:
- Region → State → Location mappings are geographically consistent (33 locations, 12 states, 5 regions)
- Role-based CTC bands enforced — every employee's CTC falls within `[ctc_min, ctc_max]`
- `retirement_date` derived from birth year + 58-year retirement age
- `years_of_service` = `retirement_date − joining_date` (contracted tenure, not elapsed tenure)
- `retiring_in_3_years` = Yes if retirement_date ≤ 2029-07-29

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org) (LTS, v18+)
- npm (bundled with Node)

### Install & run

```bash
# from the csr-dashboard folder:
npm install
npm run dev
```

Then open http://localhost:5173

### Build for production

```bash
npm run build
```

## Deployment (Vercel)

### Option A — Vercel CLI (quickest)

```bash
npm install -g vercel
vercel login
vercel --prod
```

Follow the prompts; the `vercel.json` SPA rewrite rule is already included.

### Option B — GitHub integration

1. Push this folder to a GitHub repo
2. Go to [vercel.com/new](https://vercel.com/new) → Import that repo
3. Framework preset: **Vite** → Deploy

No extra configuration needed.
